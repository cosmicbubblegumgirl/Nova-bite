# NovaBite

Standalone fine dining website with its own frontend, backend API, member portal, tasting builder, and booking flow.

## Run

```powershell
npm.cmd run dev
```

Open http://localhost:4201

Visual assets live in `public/assets`.

## API

- GET /api/health
- GET /api/site
- POST /api/register
- POST /api/login
- POST /api/custom-menus
- POST /api/bookings
